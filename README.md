## 🚀 Quick Installation Guide

1. **Install and Start XAMPP**
   - Install XAMPP on your system
   - Start Apache and MySQL services from XAMPP Control Panel

2. **Project Setup**
   - Save the project folder in: `Xampp/htdocs/`

3. **Database Setup**
   - Open your browser
   - Go to `localhost/phpmyadmin/`
   - Create a new database named `college_peoject`

4. **Access the Website**
   - Open your browser
   - Type: `localhost/[your-project-folder-name]`

## 📋 Detailed Installation Steps

### Step 1: Install and Start XAMPP
1. Download and install XAMPP from [https://www.apachefriends.org/](https://www.apachefriends.org/)
2. Open XAMPP Control Panel
3. Start Apache service (click "Start" next to Apache)
4. Start MySQL service (click "Start" next to MySQL)
5. Verify both services are running (green indicators)

### Step 2: Project Setup
1. Download the project files
2. Extract the project folder
3. Copy the entire project folder to: `C:\xampp\htdocs\`

### Step 3: Database Setup
1. Open your web browser
2. Go to `localhost/phpmyadmin/`
3. Click "New" to create a new database
4. Enter database name: `college_peoject`
5. Click "Create"
6. Select the newly created database
7. Click "Import" tab
8. Click "Choose File"
9. Select `college_peoject.sql` from your project folder
10. Click "Go" to import the database

### Step 4: Access the Website
1. Open your web browser
2. Type: `http://localhost/[your-project-folder-name]`
3. The website should now be running

## ⚠️ Common Issues and Solutions

1. **Database Connection Error**
   - Check if MySQL is running in XAMPP
   - Verify database name is exactly `college_peoject`
   - Check if password is correct in `connection.php`

2. **Page Not Found (404 Error)**
   - Verify project folder is in correct location
   - Check if Apache is running
   - Clear browser cache
   - Try accessing with correct URL: `http://localhost/[your-project-folder-name]`

3. **Permission Denied**
   - Ensure project folder has proper read/write permissions
   - Check file ownership
   - Restart XAMPP services
